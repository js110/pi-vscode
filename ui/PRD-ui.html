pi-vscode 界面与图标重设计 — HTML 原型

基于 PRD v1.4（场景 B+C，17 项核心路径）· 设计基准：VS Code 原生风格（Dark/Light Modern 变量）
右上角工具条可切换 深浅主题 与 中/英语言，四组合即 PRD 13.3 兼容性验收的可视化对应。

设计原则
原生融入：全部颜色引用 --vscode-* 变量，组件零写死色值——装进真实 webview 即自动跟随用户主题。
面板骨架：Header（新建 Tab / 会话 / 设置）→ Tab 条（状态图标常驻）→ 消息流 → 输入区（引用 chips + 模式切换器）→ Footer（模型 / 上下文用量 / 发送），与 PRD 9.1-9.3 一一对应。
状态可见：流式中（蓝 spinner）/ Plan 执行中（紫）/ 失败暂停（橙）/ 中断（红）四态图标贯穿 Tab 条、消息流与后台任务面板（9.5 Tab 状态外显）。
审批三层：自动放行留痕（虚线痕迹条）→ 审批卡（允许一次/允许并记住/拒绝 + 危险标识）→ 设置页规则管理，同一视觉语言（9.3/9.6）。
