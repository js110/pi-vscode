# pi-vscode 菜单树（UI 入口与导航交互树）

| 元信息 | 值 |
|---|---|
| 来源 | PRD v1.0（#0000，2026-09-14）第 7 节功能清单（M06）、第 9 节功能详细说明（M09） |
| 规范 | gen-menu-tree skill：L1-L5 层级 / C·F·E·D·S·T 区域 / 三段式节点编号 / state·precondition·fail·expect |
| 宿主 | VS Code 扩展（pi-vscode），区域模型按 0.1 映射 |

## 0.1 区域模型映射（Web 管理后台 → VS Code 容器）

| 代号 | skill 定义 | 本插件映射 | z-index |
|---|---|---|---|
| C区 | 主内容区，替换当前 Tab | 侧边栏主面板 Webview（活动栏图标唤起） | 1 |
| F区 | 全屏覆盖 | 编辑器区整页视图（设置页、后台任务面板） | 10 |
| E区 | 居中弹窗 | QuickPick / Webview 模态（模型选择器、会话历史、@补全、技能菜单、Apply 预览、审批范围选择） | 100 |
| D区 | 确认弹窗，始终在 E 区之上 | VS Code 原生确认对话框（单写者、追加警告、冲突提示、清空确认） | 200 |
| S区 | 侧边抽屉 | 编辑器行内浮层（Inline Chat 输入框 + 行内 diff） | 100 |
| T区 | toast / tooltip / 快捷菜单 | 通知 Toast、悬浮提示、编辑器右键菜单 | 999 |

> 尺寸规则：C/F 区用百分比，E/D 区用固定像素；S 区宽度随编辑器（百分比宽 × 固定高）。系统原生文件选择器尺寸随操作系统，不标注像素。

## 0.2 层级映射

| skill 层级 | 本插件含义 | 示例 |
|---|---|---|
| L1 | 顶部入口（活动栏 / 编辑器 / SCM / 命令面板 / 通知） | 活动栏 Pi 图标 |
| L2 | 界面 / 菜单项（面板内分区、菜单条目） | 聊天输入区、右键菜单项 |
| L3 | 功能场景（操作按钮及其行为） | 发送消息、Apply |
| L4 | 深度交互（弹窗 / 选择器 / 确认） | 模型选择器、diff 预览 |
| L5 | 反馈（toast / 通知 / 内联提示） | 凭证失效通知（见 6） |

## 0.3 一级入口总览

| 编号 | 一级入口 | 打开 / 作用界面 | 区域 |
|---|---|---|---|
| L1-A | 活动栏 Pi 图标 | 侧边栏主面板（配置接入 + 对话 + 消息流） | C区 |
| L1-B | 编辑器入口（选区右键菜单 / Inline Chat 快捷键） | 发送到 Pi / 行内对话浮层 | T区 / S区 |
| L1-C | SCM「生成 commit message」按钮 | SCM 输入框填充 | SCM 视图 |
| L1-D | 命令面板与键盘快捷键 | 各场景直达（见 5） | — |
| L1-E | 通知中心（被动入口） | 错误与后台失败反馈（见 6） | T区 |

## 1. L1-A 活动栏 Pi 图标 → C区 侧边栏主面板

```text
L1: 活动栏 [Pi 图标] → C区: 侧边栏主面板 100%×100%
│
├── L2: 面板标题栏
│   ├── MN-TAB-NEW  click [新建 Tab] → 新对话 Tab（初始对话态）
│   │               fail: { timeout: toast("操作超时，请重试") }
│   │               expect: 新 Tab 置为当前，会话状态 = 空闲
│   ├── MN-TAB-SWT  click [Tab 标签] → 切换到目标 Tab（会话、diff、流式状态按 Tab 隔离还原）
│   │               precondition: 目标 Tab 存在 | :hidden（不存在的 Tab 不渲染）
│   ├── MN-TAB-CLS  click [Tab 关闭按钮] → 关闭 Tab（会话每轮已落盘，可从会话历史找回）
│   ├── MN-HIS-OPN  click [会话历史] → L4: 会话历史 [E区 600×400px]
│   ├── MN-MDL-OPN  click [当前模型名称] → L4: 模型选择器 [E区 600×400px]
│   ├── MN-BGT-OPN  click [后台任务] → L3: 后台任务面板 [F区 100%×100%]
│   └── MN-SET-OPN  click [设置齿轮] → L3: 设置页 [F区 100%×100%]
│
├── L2: 配置接入区（启动发现，PRD 9.1）
│   ├── （事件）插件激活时只读发现 ~/.pi/agent：凭证 / 模型 / 技能 / 历史会话
│   │   state: {
│   │     loading: spinner("正在读取 Pi 配置"),
│   │     empty: 错误态卡片 = 缺失说明 + 文档链接 + 重新检测按钮（无空白面板、无配置表单），
│   │     error: "无法读取 Pi 配置（权限不足或被占用）" + click [重新检测] → CF-ERR-RDT
│   │   }
│   │   expect: 主面板呈现"已从 Pi 读取 N provider / M 模型"统计；零配置操作，30 秒内可发首条消息
│   ├── CF-ERR-RDT  click [重新检测] → 重走发现流程，成功即渲染主面板
│   │               precondition: 面板处于错误态 | :hidden（已发现态不显示）
│   │               fail: { timeout: 保持错误态 + toast("读取超时"), 500: toast(文件 + 行号级错误详情) }
│   │               expect: 无需重启 VS Code，输入草稿保留
│   ├── CF-ERR-DOC  click [查看文档] → 打开外部文档链接（T区）
│   └── （事件）环境变量凭证提示：终端可发现 pi 而当前 VS Code 进程读不到同等凭证时，
│                提示具体原因（凭证依赖的环境变量在当前进程不可见）
│
├── L2: 消息流（PRD 9.3 / 9.5）
│   ├── 代码块（渲染为增量更新，长回复滚动不卡顿）
│   │   ├── MS-CB-CPY  click [复制] → 复制代码块原文 + toast("已复制")
│   │   ├── MS-CB-FLD  click [折叠 / 展开] → 长代码块折叠切换
│   │   └── MS-CB-APL  click [Apply] → L4: Apply 预览 [E区 800×600px]
│   ├── 审批卡片（工具调用待审批；内容节点：工具名、参数摘要、危险标识）
│   │   ├── APR-ALW-ONC click [允许一次] → 放行执行（改动进 diff + checkpoint）
│   │   │                fail: { timeout: toast("工具执行超时，可用 Esc 中断"), 500: 失败结果回传 AI 继续对话 }
│   │   ├── APR-ALW-RMB click [允许并记住] → L4: 记忆范围选择 [E区 360×200px]
│   │   │                precondition: 非危险工具 | :hidden（危险工具不出现此项，永不记忆）
│   │   └── APR-RFS-DNY click [拒绝] → 不执行，拒绝结果回传 AI 继续对话
│   ├── 审批记忆命中痕迹（自动放行留痕，与手动批准视觉可区分）
│   │   └── APR-MEM-EXP click [痕迹条目] → 展开：工具名 / 放行来源 = 记忆 / 时间 / 参数摘要
│   ├── TODO 任务卡片（内容节点）：Plan 执行中实时勾选、失败项标注；压缩后卡片与计划本体仍可见
│   └── Plan 计划卡片
│       ├── PL-CRD-EDT  click [调整步骤] → 编辑计划（调整顺序 / 删减步骤）
│       ├── PL-CRD-APR  click [批准执行] → 按步骤连续自动执行（TODO 实时勾选）
│       │                precondition: 计划非空 | :disabled
│       ├── PL-CHG-LST  click [变更清单] → 查看已完成步骤按步骤 / 轮次的改动界限
│       ├── PL-CHG-RBK  click [回滚] → 按步骤 / 轮次粒度回滚（不影响其他轮次 redo 链）
│       │                fail: { 500: toast("回滚失败，已保持现状") }
│       └── （事件）执行中按 Esc → 立即停止当前与后续步骤：已完成保留、未执行标记取消，
│                    可调整计划重新批准
│
├── L2: 聊天输入区（PRD 9.2）
│   ├── IN-SND-MSG  click [发送] → 发送并进入流式回复
│   │                precondition: 输入非空 | 流式中 → 转为 FollowUp 入队（本轮结束依序发送）
│   │                fail: {
│   │                  网络: 自动重试上限 3 次，防重试风暴，队列消息不重复发送
│   │                       + toast("网络异常，已重试 3 次仍失败，内容已保留"),
│   │                  401: 流式内容保留 + toast("凭证被拒绝（401），请在终端更新 Pi 凭证")（修复后无需重启）,
│   │                  限流: 自动重试后暂停 + toast("请求被限流，已暂停，可稍后继续")
│   │                }
│   ├── IN-ESC-INT  key [Esc] → 中断流式（已生成内容保留、队列去向明确，可重试 / 续聊；状态机无死锁）
│   ├── IN-IMG-BTN  click [图片按钮] → 系统原生文件选择器（选图随消息发送，落盘为 pi 会话格式）
│   │                precondition: 当前模型支持图片输入 | :disabled + hover 提示"当前模型不支持图片输入"
│   ├── IN-IMG-PST  paste [图片] → 附件预览进入输入区（模型不支持时明确提示，不无声失败）
│   ├── IN-IMG-DND  dragTo [图片文件] → [输入区] 同粘贴路径
│   ├── IN-AT-CALL  fill [@] → L4: @-mention 补全 [E区 480×320px]
│   ├── IN-DND-FLD  dragTo [文件] → [输入区] 拖拽文件转文件引用（同 @-mention 注入路径）
│   ├── IN-SKL-CMD  fill [/] → L4: 技能菜单 [E区 480×320px]
│   ├── IN-MOD-PLN  click [Plan] → 切到 Plan 模式（输入区标注当前模式；规划中仅允许只读工具，
│   │                任何写类工具调用被拒绝）
│   └── IN-MOD-CHAT click [对话] → 切回对话模式
│
├── L2: 压缩提示条（输入区上方，上下文用量超阈值默认 80% 时出现）
│   ├── （内容节点）说明摘要将覆盖范围 + 保留清单（计划 / TODO 列入保留）
│   ├── CP-BAR-ACC  click [压缩] → 执行 Pi 原生压缩（计划 / TODO 保活）
│   │                fail: { 500: 保持原上下文不变 + toast("压缩失败，已保留完整上下文")，可改用手动命令 }
│   │                expect: 压缩后计划 / TODO 仍可见、用量回落
│   └── CP-BAR-DFR  click [暂不] → 关闭提示；同一阈值区间不重复弹出
│
└── L2: Tab 状态图标（内容节点）：流式中 / Plan 执行中 / 失败暂停；
    （事件）后台 Tab 失败 → 发出通知（见 6）
```

## 2. 二级界面与弹窗（从主面板标题栏 / 命令面板打开）

### 2.1 模型选择器 [E区 600×400px]

```text
L4: 模型选择器
├── MD-SEL-FLTR  fill [过滤框] → 即时过滤（100+ 条目过滤 ≤ 100 毫秒，不卡顿）
├── MD-SEL-PICK  click [模型条目] → 应用为当前 Tab 模型并关闭
│                 expect: 列表与终端 /model 一致（含自定义条目，按 pi 合并语义）；费率缺失显示"未知费率"
│                 fail: { 401: toast("凭证被拒绝（401），请在终端更新 Pi 凭证") }
└── （事件）打开选择器即热刷新配置：外部修改 models.json 无需重启即反映；
     解析失败保留上一个可用列表 + 文件 + 行号级错误（部分可用态，不整体失败）；
     进行中会话的模型被删除 → D区 提示换模型（见 2.7）
```

### 2.2 会话历史 [E区 600×400px]

```text
L4: 会话历史
├── HS-LST-FLTR  fill [搜索框] → 按项目 / 时间过滤（200+ 会话首屏 ≤ 1 秒，虚拟化 / 分页）
├── HS-LST-PICK  click [会话条目] → 加载会话（上下文、token 用量与终端一致，Turn 序号延续）
│                 state: {
│                   loading: skeleton(会话消息列表骨架),
│                   empty: "暂无会话",
│                   error: "会话文件损坏，已跳过：xxx"（跳过该会话，不拖垮历史列表）
│                 }
│                 fail: { 占用: → D区 单写者确认（见 2.7）；模型下架: → D区 选择替代模型 }
└── expect: 加载终端 CLI 产生的会话后继续对话，终端 pi --continue 能读回全部轮次
```

```text
L3: 设置页
```

### 2.7 确认对话框汇总 [D区]

```text
D区: 单写者确认 [420×220px]（加载正被其他窗口 / 终端写入的会话时触发）

└── HS-OPN-TKO  click [接管] → 本窗口获得写入权

D区: Inline Chat 冲突 [420×220px]（接受前存在未保存手改，或生成期间同文件被编辑时触发）
├── ED-CNF-CONT click [仍要接受] → 由用户确认后应用
└── ED-CNF-CCL  click [取消] → 不应用，保持文件现状
```

## 3. L1-B 编辑器入口

### 3.1 选区右键菜单 [T区]

```text
L1: 编辑器选区右键菜单 [T区]
├── ED-CTX-SND  click [发送到 Pi（当前 Tab）] → 选区代码 + 文件路径 + 行号注入当前 Tab 并聚焦输入区
│               precondition: 存在当前 Tab | fail: { 无 Tab: 自动新建 Tab }
└── ED-CTX-SNB  click [发送到 Pi（新 Tab）] → 新建 Tab 并注入选区上下文
```

### 3.2 Inline Chat 行内浮层 [S区 100%×160px]

```text
L1: 编辑器内快捷键 → S区: 行内浮层（输入框 + 行内 diff，宽度随编辑器）
├── ED-INL-CALL  key [快捷键] → 呼出行内输入框（指令携带选区上下文）
│                precondition: 编辑器存在选区 | :hidden
├── ED-INL-SEND  click [发送指令] → 生成行内 diff（未落盘呈现）
│                state: { loading: spinner("生成中") }
│                fail: { 中断: 已生成内容保留；生成期间同文件被编辑 → 应用前 D区 提示"文件已变化"由用户决定 }
├── ED-DFD-FLD   click [折叠] → diff 过大时折叠
├── ED-DFD-JMP   click [跳转] → 跳转到对应 diff 块（不阻塞编辑器导航）
├── ED-INL-ACC   click [接受] → 文件更新并纳入本 Tab diff / checkpoint 体系（可回滚）
│                precondition: 无未保存手改 | fail: { 未保存手改: D区 冲突提示，不静默混合 }
├── ED-INL-ABN   click [放弃] → 文件保持原状不落盘；多轮追加修改后一次放弃回到最初状态
└── ED-INL-APP   click [追加指令] → 在同一浮层继续对话式修改
```

## 6. L1-E 通知与全局反馈（T区，文案详见 PRD M11）

| 反馈 | 触发 | 呈现 |
|---|---|---|
| 后台 Tab 失败通知 | 后台 Tab / 后台任务失败 | 通知（Tab 标题状态图标同步） |
| 凭证失效 | 401 / 403 | 区分于网络错误，流式内容保留，修复后无需重启 |
| 限流暂停 | provider 连续限流 | 自动重试后暂停当前步，不把失败当完成 |
| 压缩失败 | 压缩请求报错 | 保持原上下文，可改用手动命令 |
| 网络重试失败 | 反复断续达上限 | 内容保留，手动重发 |
| 环境变量凭证提示 | 进程读不到 shell 凭证 | 给出具体原因与建议动作 |
| 会话损坏跳过 | 会话文件损坏 / 截断 | 提示跳过条目，不拖垮列表 |
| 会话占用 | 终端 CLI 正在写入 | 只读加载或占用提示 |
| 文件修改被拒 | AI 改文件被权限拒绝 | 前 N-1 个保留，清单标出失败点 |
| 引用文件被删 | @-mention 文件发送前被删 | 明确提示，不无声失败 |
